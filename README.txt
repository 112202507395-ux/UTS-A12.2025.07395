RUANG BIJI — FULL SOURCE CODE

File:
- index.html : struktur landing page dan formulir Bootstrap
- style.css  : tampilan, hover, dan responsive
- script.js  : kalkulator, filter, modal produk, dan validasi formulir

Cara pakai:
1. Ganti ISI_NIM_KAMU dan ISI_NAMA_LENGKAP_KAMU di bagian footer index.html.
2. Simpan ketiga file di folder yang sama.
3. Buka index.html dengan Live Server atau browser.
4. Koneksi internet dibutuhkan untuk Bootstrap CDN, Google Fonts, dan foto Unsplash.

Catatan: formulir hanya demo validasi di sisi browser. Data tidak disimpan atau dikirim ke server.
